# Applied Computational Genomics Coursework

My worked exercises and reproducible notes from Dr. Aaron Quinlan's Applied
Computational Genomics lecture series. The repository focuses on practical Unix
and bioinformatics workflows for genomic annotation, sequence analysis, quality
control, and read alignment.

## Course resources

- [Applied Computational Genomics lectures](https://www.youtube.com/playlist?list=PLCbXw1opqIQeNfF26-wWegdGoCC1aut0P)
- [Original homework assignments](https://gist.github.com/arq5x/c0eb84bce2086fbfbe9184668ef87b31)

## Repository contents

| Directory | Topics | Status |
| --- | --- | --- |
| `homework-01/` | Unix pipelines and Ensembl GTF annotation | Partial worked notebook |
| `homework-02/` | FASTA processing, GC content, and sequence motifs | Partial worked notebook |
| `homework-03/` | FASTQ quality, SAM/BAM processing, and variant evidence | In progress |

Large reference sequences, reads, alignments, generated FastQC reports, and
private answer notes are intentionally excluded from Git. Each exercise records
the commands needed to obtain or regenerate its inputs.
